### 1. Executive Summary & Context
In Sprint 521, we successfully implemented symmetric W4A32 quantization and AVX2 CPU SIMD execution, shrinking all 42 manifold layers from 3.95 GB to 1.87 GB.
However, during interactive autoregressive decode:
1. **GPU VRAM Utilization Gap**: Only INT8 GPU resident layers were supported, requiring ~94 MB per layer (3.95 GB total). At 1.87 GB, INT4 layers can easily reside 100% within the 8 GB GDDR6 VRAM of Rick's NVIDIA RTX 2000 Ada laptop GPU.
2. **Synchronous Staging Bottleneck ([`[ISSUE-372]`](file:///C:/Users/rich-/source/repos/CARTAN/ISSUES.md))**: In `src/std/wgpu.cl` (`cartan_wgpu_dispatch_fused_geglu_down_read`), each layer forward executes `wgpuBufferMapAsync` followed by a blocking spin-poll loop (`wgpuDevicePoll(g_wgpu_device, 1.0, 0.0)`), forcing the host CPU to block synchronously 42 times per token.

Sprint 522 resolves both bottlenecks:
- Implementing vectorized INT4 WGSL compute shaders for GeGLU and Down projections.
- Mounting all 42 INT4 layers directly into physical GPU VRAM at boot (total 1.87 GB).
- Implementing ping-pong double-buffered staging buffers in `src/std/wgpu.cl`.

### 3. Codebase Analysis & Findings

#### A. INT4 WGSL Bit Unpacking Mathematical Verification
In INT4 layers generated by `tools/quantize_manifold_int4.car`:
- Packed byte $B$ has low nibble $w_{2k}$ (bits 0..3) and high nibble $w_{2k+1}$ (bits 4..7).
- In a 32-bit `u32` containing four packed bytes, low nibbles contain four even weights $(w_0, w_2, w_4, w_6)$ and high nibbles contain four odd weights $(w_1, w_3, w_5, w_7)$.
- **WGSL SIMD Unpacking Scheme**:
  ```wgsl
  let raw: u32 = layer_weights[idx];
  let v_low = unpack4x8unorm(raw & 0x0F0F0F0Fu) * 255.0f;
  let signed_low = select(v_low, v_low - 16.0f, v_low >= vec4<f32>(8.0f));

  let v_high = unpack4x8unorm((raw >> 4u) & 0x0F0F0F0Fu) * 255.0f;
  let signed_high = select(v_high, v_high - 16.0f, v_high >= vec4<f32>(8.0f));

  let w0123 = vec4<f32>(signed_low.x, signed_high.x, signed_low.y, signed_high.y);
  let w4567 = vec4<f32>(signed_low.z, signed_high.z, signed_low.w, signed_high.w);
  ```
  This is 100% branchless, vector-fused, and mathematically exact with zero cross-byte borrow anomalies.

#### B. Memory Offsets for INT4 WGSL Shaders
For sliding-window layers ($l \not\equiv 5 \pmod 6$):
- Gate weights: $10240 \times 2560 \times 0.5 = 13,107,200$ bytes = $3,276,800$ `u32` words.
- Scales: $10240$ floats.
- Offsets within the INT4 layer buffer:
  - Header: 64 bytes = 16 words.
  - Normalization: $2560 \times 4 = 10240$ bytes.
  - Q/K/V/O INT4 bytes and scales...
  - Gate scales: float index offset $bo_{scales} / 4$.
  - Gate weights: word offset $bo_{weights} / 4$.
  - Up scales & weights...
  - Down scales & weights...
  These offsets must be calculated with byte-level precision to match the layout in `tools/quantize_manifold_int4.car`.

#### C. Double-Buffered Staging ([`[ISSUE-372]`](file:///C:/Users/rich-/source/repos/CARTAN/ISSUES.md))
- Currently, `g_wgpu_persistent_staging_buf` is a single buffer.

### 4. Technical Debt & Safety Invariants
- **Zero-Mock Rule**: All GPU buffers, WGSL shaders, and memory copies must execute authentic calculations.
- **VRAM Boundary Safety**: 42 layers $\times 46.6$ MB = 1.95 GB VRAM. Total RTX 2000 Ada VRAM is 8 GB. Leaving >6 GB free guarantees zero VRAM overflow or paging to system RAM.
- **Fallback Guarantee**: If WebGPU initialization fails on machines without compatible physical GPUs, the runtime must cleanly fall back to the CPU AVX2 INT4 engine implemented in Sprint 521.
