# Rewrite Initialization Pipeline for Continuous Embeddings

Currently, `build_bpe_embeddings.py` randomly scrambles all 256k tokens onto the surface of the $S^{247}$ hypersphere. The hierarchical JSON datasets (WordNet, Math, Physics) that were once used in the SQLite database are now completely bypassed.

We will rewrite the initialization pipeline to mathematically embed these taxonomies directly into the `.npy` coordinate array, giving the model a massive topological "head start" without suffering the I/O bottlenecks of a SQLite database.

## User Review Required

> [!IMPORTANT]
> Because WordNet defines concepts (e.g., "accomplishment") but Gemma uses BPE subwords (e.g., " accom", "plish", "ment"), there is not a perfect 1:1 mapping. We need to decide how to handle the unmapped BPE tokens.
> 
> **Proposed Strategy**: For every token in the vocabulary, we decode it to its raw text. If the text exactly matches a concept in our JSON trees (including SlangNet to capture informal terminology), we assign it the exact top-down deterministic coordinate. If it does not match (which will be true for partial subwords and grammar syntax), we generate a pseudo-random coordinate based on the SHA256 hash of the subword. The model's pretraining will naturally "pull" these subwords toward their parent concepts over time.
>
> Does this strategy align with your vision, or would you prefer a more complex matching algorithm (e.g., averaging the coordinates of all words that contain a specific subword)?

## Proposed Changes

### [NEW] `utils/initialization/build_topological_embeddings.py`

We will create a new initialization script that replaces `build_bpe_embeddings.py` and the old `import_semantic_tree.py`. 

- **Step 1: Top-Down Tree Expansion**
  Load all JSON datasets (`msc2020.json`, `semantic_tree.json`, and an imported `slangnet.json` to handle informal OOV terminology). Iterate top-down using a deterministic SHA-256 hash of the lemmas to calculate 248D direction vectors. Apply the $E_8$ lattice snapping, mimicking exactly how `import_semantic_tree.py` mapped the topology. Store this in a temporary Python dictionary: `lemma -> 248D coordinate`.

- **Step 2: Vocabulary Mapping**
  Load the Gemma tokenizer (`vocab_size ~256k`). For `idx = 0` to `vocab_size`:
  - Decode the token to string (e.g., `token[idx] -> text`).
  - If `text` exists in the `lemma -> coordinate` dictionary, assign `embeddings[idx] = coordinate`.
  - Else, generate a deterministic random coordinate `embeddings[idx] = SHA256(text)_coordinate`.

- **Step 3: Hypersphere Projection**
  Normalize the entire `embeddings` array to the surface of the $S^{247}$ hypersphere to conform with the Riemannian optimization engine.

- **Step 4: Save**
  Output `checkpoints/geomind_e8_embeddings.npy` and `checkpoints/geomind_ics.npy`.

### [MODIFY] `launch.py` and `master_init.py`

We will update the pipeline scripts to point to `build_topological_embeddings.py` instead of the deprecated database generation scripts.
