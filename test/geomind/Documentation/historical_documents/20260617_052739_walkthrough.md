# Walkthrough: Morpheme Emission & Causal Dataset Compilation

We've successfully refactored the tokenizer and rebuilt the primary causal dataset to integrate WordNet's morphological boundaries! 

## 1. The Morpheme Emission Tokenizer
The core `WordTokenizer` (`core/word_tokenizer.py`) has been upgraded from a naive dictionary-matcher into a dynamically emitting hybrid tokenizer:
- **Base Semantics:** Words are directly mapped to their 248D semantic coordinate on the E8 lattice if they exist natively in WordNet (e.g. "disagree", "running").
- **Morphological Stripping:** If a word is inflected (e.g., "beans", "jogged") and isn't native to the DB, the tokenizer intercepts it using `nltk.WordNetLemmatizer`.
- **Morpheme Emission:** Upon stripping a suffix, the tokenizer explicitly emits the stripped grammatical role as a dedicated coordinate primitive (e.g. `[PLURAL]`, `[PAST_TENSE]`, `[PRESENT_PARTICIPLE]`, `[THIRD_PERSON_SINGULAR]`). 

> [!NOTE]
> Prefix parsing (like `un-`, `dis-`) does not require morpheme emission because WordNet inherently treats derivational shifts (which alter the fundamental semantic meaning) as completely distinct base lemmas with their own distinct coordinates!

## 2. Dataset Pre-Compilation
The `build_causal_dataset.py` pipeline was completely refactored to support dynamic morpheme expansion:
- Built a robust, two-pass line-streaming architecture to prevent NLTK from choking on massive file chunking.
- Implemented OOV caching (`_oov_cache`) during tokenization, boosting throughput from 4k tokens/sec to **~7k tokens/sec**.

## 3. The 27-Gigabyte Milestone
The `ohsuz_tiny-textbooks-merged_train.txt` corpus has been successfully translated from English text into raw mathematically encoded E8 spatial coordinates:
- **Corpus Lines:** 1,785,683
- **Final Coordinates (Tokens):** 29,150,778
- **File Size:** 27.68 GB (`_e8_coords.npy`)

The sequence engine is now mathematically primed to learn English syntax dynamically from the sequential juxtaposition of base semantics and emitted grammatical rules!
